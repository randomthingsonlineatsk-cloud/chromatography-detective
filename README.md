# Chromatography Detective

Diagnose what is wrong with a fictional HPLC chromatogram.

**Live demo:** https://macaly-kvhkhcuynsxv8osycr1em9r4-prod.macaly-app.com

> This is a fictional, educational demonstration. Do not use it for real patient data, clinical decisions or regulatory submissions.

## Features
- 100 cases: 20 fault categories x 5 variants (tailing, fronting, drift, ghost peaks and more)
- Case navigator with filters, shuffle, difficulty tags and a leaderboard
- Save/load progress and a downloadable study sheet

## Tech stack
Built on Macaly Cloud.
